# ReleaseSwitch

**Версия 1.2.1** — утилита для встроенной клавиатуры MacBook с Apple Silicon: Fn меняет язык при отпускании, а Caps Lock включает заглавные без штатной задержки.

**[Скачать ReleaseSwitch.dmg](https://github.com/worker14289601/ReleaseSwitch/releases/latest/download/ReleaseSwitch.dmg)** · [Все версии](https://github.com/worker14289601/ReleaseSwitch/releases)

## Требования

- MacBook с Apple Silicon (arm64).
- macOS 26 или новее. Программа проверялась на macOS 27 на MacBook Air 13 M4. **На macOS 26 не тестировалась и может работать нестабильно.**
- Как минимум две включённые раскладки для переключения языка.

## Возможности

- **Fn / 🌐:** одиночное нажатие меняет язык после отпускания независимо от длительности удержания. Нажатие другой клавиши во время удержания отменяет переключение; сочетания Fn сохраняют обычное действие.
- **Caps Lock:** отключение задержки включения заглавных. Регистр и индикатор переключаются штатным механизмом macOS.
- Автозапуск при входе в систему.
- Переключатель «Показывать в строке меню»: значок можно скрыть, выбор сохраняется после перезапуска.
- Проверка клавиш, состояние разрешений и копирование диагностики.

Текст и история нажатий не сохраняются. Сетевой доступ приложению не нужен. Текст из окна проверки удаляется при его закрытии.

## Установка

1. Скачайте и откройте [ReleaseSwitch.dmg](https://github.com/worker14289601/ReleaseSwitch/releases/latest/download/ReleaseSwitch.dmg).
2. Перетащите ReleaseSwitch на папку «Программы» в окне образа.
3. Запустите установленную копию из «Программ».
4. Нажмите «Разрешить доступ…» и выдайте запрошенные разрешения. На macOS 27 соответствующий раздел называется «Конфиденциальность и безопасность → Управление устройством и доступ к данным»; также может требоваться «Мониторинг ввода». На macOS 26 раздел доступа может называться «Универсальный доступ».
5. В «Системные настройки → Клавиатура» для одиночного нажатия 🌐 выберите «Действие не требуется». Кнопка «Настроить…» в приложении открывает настройки клавиатуры.
6. Нажмите «Проверить клавиши» и проверьте быстрые и долгие нажатия Fn, сочетания Fn + Shift / Fn + стрелки и включение/выключение Caps Lock.

Запуск прямо из DMG показывает подсказку об установке. Обработка клавиатуры и регистрация автозапуска выполняются установленной копией. Для готовой программы инструменты сборки не требуются.

## Использование

Fn и Caps Lock можно включать независимо. Переключатель «Запускать при входе» управляет автозапуском; если macOS требует подтверждения, приложение предлагает открыть системные настройки.

Закрытие окна и скрытие значка в строке меню не останавливают программу. Чтобы открыть окно снова, запустите ReleaseSwitch из «Программ».

«Отключить и восстановить настройки» выключает функции и автозапуск, возвращая сохранённые исходные настройки клавиш. Пункт меню «Выйти и восстановить клавиши» завершает программу и восстанавливает клавиши; настройка автозапуска при этом сохраняется.

## Если что-то не работает

- Проверьте разрешения и наличие двух раскладок. После изменения разрешений при необходимости нажмите «Перезапустить приложение».
- Если после обновления доступ включён, но не принимается, удалите только запись ReleaseSwitch из соответствующего раздела разрешений и добавьте установленную копию заново.
- При защищённом вводе macOS обработка Fn приостанавливается и автоматически возобновляется после его завершения. Незавершённое нажатие отбрасывается — нажмите Fn снова.
- Кнопка «Скопировать диагностику» копирует текущее состояние. Оно также доступно в `~/Library/Application Support/ReleaseSwitch/status.json`; вводимый текст туда не попадает.

Внешние клавиатуры отдельно не проверялись. Отключение задержки Caps Lock применяется к встроенной клавиатуре. Работа на всех подверсиях macOS 26 не подтверждена.

## Обновление и удаление

Перед заменой приложения завершите работающую копию через меню ReleaseSwitch. После обновления macOS может потребовать выдать доступ заново.

Перед удалением нажмите «Отключить и восстановить настройки», затем завершите программу через её меню и переместите ReleaseSwitch из «Программ» в Корзину. Если значок скрыт, сначала включите его в окне программы.

## Сборка

Нужны Mac с Apple Silicon, Xcode Command Line Tools с SDK macOS 27 и Python 3 с pip для упаковки DMG.

В папке проекта выполните:

```sh
zsh build.sh
zsh build-dmg.sh
```

`build.sh` запускает 54 регрессионные проверки и создаёт `ReleaseSwitch.app` (arm64, минимальная macOS 26.0). `build-dmg.sh` создаёт `ReleaseSwitch.dmg`; зависимости упаковщика устанавливаются только в `build/dmg-tools` согласно `Scripts/dmg-requirements.txt`.

## Файлы проекта

- `Sources/` — весь код приложения на Swift и заголовок HID.
- `Resources/` — иконки и фон установочного образа.
- `Scripts/` — создание ресурсов, настройка DMG и зависимости упаковщика.
- `Tests/` — регрессионные и интеграционные проверки. Проверки с реальным вводом и установленным приложением запускаются отдельно от обычной сборки.
- `Info.plist` — версия, требования и параметры приложения.
- `build.sh`, `build-dmg.sh` — сборка приложения и образа.
- `install.sh`, `uninstall.sh` — дополнительные скрипты установки и отключения с восстановлением настроек. Для обычной установки используйте DMG. Перед `install.sh` нужна сборка; `uninstall.sh` оставляет удаление самого приложения пользователю.
- Готовый образ `ReleaseSwitch.dmg` и его контрольная сумма `ReleaseSwitch.dmg.sha256` доступны в [Releases](https://github.com/worker14289601/ReleaseSwitch/releases).
